# Sankeerth Naidu Portfolio

A modern portfolio website for Sankeerth Naidu, showcasing AI/ML engineering work, GenAI projects, NLP and RAG systems, and contact information for opportunities.

## Overview

This portfolio is built with React and Vite to present:

- AI/ML engineer profile and positioning
- Core technical capabilities
- Featured AI and ML projects
- Contact information and social links
- A sleek dark, futuristic UI

## Tech Stack

- React
- Vite
- Tailwind CSS
- GSAP
- EmailJS

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Production Build

```bash
npm run build
```
